# seamud_data_isme_202605

Data package for the ISME journal paper:
**“Season-linked microbial consortium accelerates iron corrosion in marine sediments via coupled acidification and electron transfer processes”**

## Sampling design
Environmental samples were collected in **April (Spring)**, **August (Summer)**, and **December (Winter)** of **2024** from an **offshore wind-farm area** in the **South China Sea**.

- Sampling location (GPS): **22.72898°N, 115.608873°E**

## Files included
- **table_filtered_w_tax.xls**  
  Filtered data table with taxonomic information (fields/columns are defined in the sheet headers).

- **rep_seqs.fna.gz**  
  Gzipped FASTA file containing **representative sequences** (DNA; `.fna` format).

## Notes
- Contents and column definitions for `table_filtered_w_tax.xls` should be confirmed by the file’s worksheet headers.
- `rep_seqs.fna.gz` should be decompressed prior to downstream sequence analysis.
